# 🎁 GiftTracker 🎁

Welcome to the **GiftTracker** project page. 

GiftTracker is an easy-to-use app for recording and remembering birthdays and gift ideas. 
Save names, birthdays, gift ideas, and vendor websites to simplify tracking your gifting. 

This project is authored by *Eric Robinson*.
